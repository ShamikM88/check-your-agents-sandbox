# Check Your Agents sandbox

Synthetic test data for Check Your Agents, an open-source accountability protocol for multi-agent work.

Everything in this repository is made up: test ledgers, sample pull requests, sample documents and the
example repository state they refer to. Nothing here is real work, no entry is a real person's decision, and no
task, name or figure refers to a real project.
